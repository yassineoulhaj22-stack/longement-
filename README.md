# Havaura – Android (APK)

Application de location de studios à Rabat (Capacitor + HTML/CSS/JS).

## Obtenir l'APK
1. Créez un dépôt GitHub et envoyez-y tous les fichiers de ce ZIP (dossier `.github` inclus).
2. Onglet **Actions** > **Build APK** > **Run workflow** (se lance aussi à chaque push).
3. Une fois terminé, téléchargez l'artefact **havaura-apk** (APK debug installable).

## Modifier l'app
Tout le code est dans `www/` (`index.html`, `style.css`, `app.js`). Remplacez les dégradés par de vraies photos dans `www/img/`.
